# Generador QR con Astro

🚀 **Sitio en vivo:** [https://generador-de-qr-s32y.vercel.app/](https://generador-de-qr-s32y.vercel.app/)

**Opción elegida:** C

**Por qué elegí esta opción:** 
La elegí porque es útil para un caso real de generación de códigos QR, permite aprender SSR (Server-Side Rendering) en Astro y cómo manejar envío de formularios nativos procesados del lado del servidor sin depender de frameworks adicionales en el cliente.

## Características

- 🎨 **Diseño Premium**: Interfaz moderna, clara y amigable.
- 🚀 **Astro SSR**: Renderizado en el servidor para el manejo seguro y ágil del formulario.
- 📲 **Compartir vía WhatsApp**: Permite compartir fácilmente el código generado.
- 💾 **Base de datos local**: Guarda el historial de los QRs generados usando JSON de manera local.

## Pasos para correr el proyecto localmente

1. Clona el repositorio e ingresa al directorio del proyecto.
2. Instala las dependencias:

```bash
npm install
```

3. Inicia el servidor de desarrollo:

```bash
npm run dev
```

4. Abre tu navegador en la dirección indicada en la terminal (usualmente `http://localhost:4321`).
